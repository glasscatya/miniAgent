miniAgent

一个只做一件事的 Windows 本机 agent。

它是什么

把一句话任务交给模型，模型每轮可以执行一条 PowerShell 命令，看到结果后继续，直到给出答案。没有插件、没有沙箱、没有审批环节。

三条设计取舍

  • 只有一个工具 —— pwsh。机器上装了什么，它就能用什么。
  • 无状态 —— 每次调用都是新进程，变量和 cd 不保留。
  • 非交互 —— 命令必须自问自答，不能等待输入。

运行

python .\agent.py
python .\agent.py "列出当前目录的 Python 文件"

依赖：Python 3.11+，无需第三方库。模型接口为 OpenAI 风格的 chat/completions。

边界

模型生成的命令会以当前用户权限直接执行，可以读写删除文件、访问网络。请只在可信目录或隔离环境中使用，并留意运行时的 [tool] 预览。

单入口 · 单工具 · 无对话持久化
